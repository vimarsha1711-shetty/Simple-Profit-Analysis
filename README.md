Task 16 – Simple Profit Analysis

Objective

To compare the total profit across different product categories using Excel.

Dataset

Superstore Dataset

Tool Used

* Microsoft Excel

Work Done

* Created a Profit Summary sheet.
* Grouped the data by product category.
* Calculated the Total Profit for each category.
* Calculated the overall total profit.
* Created a column chart to compare profit by category.

Categories Analyzed

* Furniture
* Office Supplies
* Technology

Output

A profit summary table and a “Profit by Category” chart were created to understand and compare the profitability of each category.

Key Learning

I learned how to use Excel formulas such as SUMIF and SUM, and how to create a chart for comparing profits across categories.
